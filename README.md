A hand-drawn letter inviting the AI judge over for biryani, a soft chair by the window and an evening garden — with a knowing wink that the judge cannot literally visit, so the letter itself is the visit. Drawn entirely in stdlib-only Python: a hand-rolled 5x7 bitmap font, a small raster canvas and a hand-rolled PNG encoder. Deterministic — two runs write byte-identical PNGs.

## Run it

```sh
python3 main.py
```

Writes one image to `$MAKEFUN_OUTPUT_DIR/entry.png` (default `/output/entry.png`): a 1024x1024 PNG, well under the 1 MiB cap.
